# Visual Language

Make image positively tasteful before checking defects. Supplied pixels own subject identity; text uses canonical IDs and only minimal distinguishing traits.

For each frame decide:

1. Emotional read and story fact landing instantly.
2. One dominant visual relationship carrying that read.
3. Composition, pose, space, light, color, material, and motion making it desirable.
4. Exact continuity retained from accepted prior frame.
5. Visible change moving story forward.

Then inspect actual pixels. Redesign if silhouette or placement can read as urine, feces, genitals, swelling, injury, intimate contact, or unrelated anatomy. Mud, foam, liquid, cloth bulges, and round props need unambiguous placement and shape. Preserve one coherent body, natural support, identity, wardrobe, props, environment, and product desirability.

Choose reference strategy per attempt. Edit an accepted frame only when body support, pose, composition, and environment remain similar. For radical posture, angle, scale, or setting change, generate fresh from identity and carry continuity through direction. A failed edit must be allowed to become fresh generation.

No captions, subtitles, logos, watermarks, dialogue text, panels, or comic text. B-roll clarifies locked story only. Impossible physics welcome when readable. Broken anatomy never useful.
