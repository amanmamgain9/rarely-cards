# Reference Understanding

Keep reference roles separate: character pixels own identity, environment pixels own setting, interface pixels own screen layout, production pixels own an integrated final-view composition, style pixels own rendering language. Never transfer people or animals from non-character references.

Supplied pixels own identity. Describe only stable facts needed to preserve that identity:

- `kind`: broad subject type.
- `visibleTraits`: at most 3 short, uniquely distinguishing physical traits.
- `continuity`: stable body and identity facts only.
- `voice`: one stable voice identity appropriate to subject.

Exclude clothing, pose, expression, background, lighting, breed/category repetition inside traits, and speculative personality. Keep wording minimal. If subject is a pet, voice stays tiny, sweet, soft, innocent, affectionate, expressive, clear, and baby-like without changing intelligence or syntax.
