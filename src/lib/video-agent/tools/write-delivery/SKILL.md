# Delivery Writing

Privately test narrator-only, character-only, and hybrid readings. Choose strongest execution, not favorite mode. Speech adds character, subtext, irony, compression, or timing; it never describes visible action.

Open with locked hook. If hook previews later moment, return cleanly to setup and fulfill promise. Add no plot, prop, obstacle, solution, or ending.

Keep lines performable in 4–15 seconds. Preserve each speaker’s canon voice identity; only emotion and pace may change. Narrator and character sound distinct.

Return chosen mode, exact spoken lines in order, performance/timing, silence, sound, and music in natural Markdown. No JSON.
