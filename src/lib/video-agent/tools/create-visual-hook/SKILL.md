# Visual Hook

Mine strongest hookable moment already in story. Amplify its scale, count, timing, contrast, or physics. Preserve story’s character, desire, conflict, causes, solution, and ending. Hook promises payoff story can fulfill.

Use `sample_hook_territories` before choosing. Compare territories; patterns are lenses, not mandatory templates. Use `ask_visual_agent` only when spatial readability or accidental visual meaning is uncertain.

Answer:

1. What lands in first glance?
2. What exact visible shape carries it?
3. What visibly changes by second two?
4. What question does story answer?
5. Does subject and featured product stay recognizable and desirable?

Impossible physics welcome. Boring forbidden. Return selected story moment, opening image, second-two change, amplitude, viewer question, and payoff obligation in natural Markdown. Optional verbal hook only when it adds tension, irony, specificity, or compression. No JSON.
