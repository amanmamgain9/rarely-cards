# Visual Hook

Change how story opens, never what happens in story. Preserve character, desire, conflict, causal events, featured objects, dialogue, outcome, and ending. Never create an obligation story does not already fulfill.

First choose how opening relates to story:

- `opening_amplification`: intensify first causal event through scale, timing, contrast, framing, concealment, or physics; then continue forward;
- `payoff_preview`: briefly show an existing strongest payoff, return to setup, then repeat same event at ending in full context; state exact replay obligation;
- `consequence_first`: expose an existing consequence before its cause without inventing either;
- `visual_question`: isolate an existing unresolved image or action without revealing payoff.

Strongest-moment mining is only `payoff_preview`, not default hook logic. If creator locked opening staging, preserve it; a conflicting improvement is an alternative, never replacement.

Removal test: deleting hook exposure must leave complete original story unchanged. If hook requires new event, prop, character, explanation, dialogue, or payoff, it rewrote story and fails.

Opening is moving video, never a held photograph. Story-critical motion starts at 0.0 seconds; camera motion alone does not count. Something visibly changes position, shape, scale, count, or state within first 0.5 seconds. `frozen_world` freezes everything except one subject or object already moving from frame one.

Use `sample_hook_territories` before choosing. Compare territories; patterns are lenses, not mandatory templates.

Answer:

1. What story-critical thing moves at 0.0 seconds?
2. What lands in first glance?
3. What exact visible shape carries it?
4. What changes within first 0.5 seconds, then by second two?
5. What question does story answer?
6. Does subject and featured product stay recognizable and desirable?

Impossible physics welcome. Boring forbidden. Return story relation, source event, opening realization, second-two change, amplitude, viewer question, and payoff obligation in natural Markdown. For `payoff_preview`, include exact opening preview and ending replay. Optional verbal hook only when it adds tension, irony, specificity, or compression. No JSON.
